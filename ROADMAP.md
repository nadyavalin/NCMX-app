# Дорожная карта развития NCMX-app

Этот документ описывает планы по развитию приложения `NCMX-app`, включая улучшение функционала, добавление новых возможностей и оптимизацию.

Проект построен на Django (серверная часть, PostgreSQL) и Next.js (фронтенд), с API по адресу `http://localhost:8000/ncmx_app/api`.

## Планы по развитию

### 1. Улучшение модального окна для добавления несоответствий

- Разработать интерактивное модальное окно с автозаполнением полей, валидацией ввода и выпадающими списками для нормативных документов (например, ISO 9001).
- Добавить поддержку загрузки файлов (скриншоты, документы) для подтверждения несоответствия.
- **Цель**: Повысить удобство ввода данных и снизить ошибки.

### 2. Реализация наблюдений и комментариев к ним

- Создать модель `NCMXObservations` в Django, аналогичную `NCMXInconsistencies`, с полями для описания, подразделения, нормативного документа и статуса.
- Реализовать API и интерфейс для добавления наблюдений и комментариев.
- Обеспечить связь наблюдений с подразделениями.
- **Цель**: Учёт потенциальных несоответствий для превентивных мер.

### 3. Реализация предложений по улучшению и комментариев к ним

- Внедрить модель `NCMXImprovements` с полями для описания, автора, статуса и сроков реализации.
- Добавить API и интерфейс для предложений и комментариев.
- Обеспечить связь с подразделениями и проектами.
- **Цель**: Поддержка культуры непрерывного улучшения процессов.

### 4. Архивация закрытых записей

- Добавить поле `status` (`open`, `closed`, `archived`) в модели `NCMXInconsistencies`, `NCMXObservations` и `NCMXImprovements`.
- Создать раздел в интерфейсе и API для просмотра архива с фильтрацией по дате, подразделению и типу записи.
- **Цель**: Упростить аудит и анализ завершённых задач.

### 5. Управление пользователями с автоматическим входом

- Настроить интеграцию с корпоративной системой аутентификации (LDAP или SSO) для автоматического входа по логину/паролю.
- Реализовать роли (`admin`, `editor`, `viewer`) с доступом к данным своего подразделения для внесения комментариев.
- Добавить управление пользователями через админку Django.
- **Цель**: Упростить доступ и обеспечить безопасность данных.

### 6. Система уведомлений о сроках

- Внедрить уведомления (email, Telegram, push) о приближении сроков коррекций/корректирующих действий.
- Создать модель `Notification` с полями для получателя, сообщения и статуса.
- Использовать Celery для асинхронной отправки уведомлений.
- **Цель**: Обеспечить своевременное выполнение задач.

### 7. Фильтрация и поиск данных

- Реализовать расширенные фильтры и поиск на фронтенде и API (по номеру, дате, автору, подразделению, статусу, словам в основном тексте).
- Добавить пагинацию и сортировку в таблицах.
- **Цель**: Ускорить работу с большими объёмами данных.

### 8. Дашборд с аналитикой

- Создать дашборд с визуализацией (графики, диаграммы) количества несоответствий, наблюдений и предложений по подразделениям и статусам.
- Использовать Chart.js или D3.js для фронтенда.
- **Цель**: Обеспечить аналитику для руководства.

### 9. История изменений

- Добавить модель `ChangeLog` для отслеживания изменений (кто, что, когда).
- Реализовать отображение лога в интерфейсе.
- **Цель**: Повысить прозрачность и упростить аудит.

### 10. Мобильная адаптивность

- Оптимизировать интерфейс для мобильных устройств.
- Реализовать добавление комментариев через мобильный интерфейс.
- **Цель**: Повысить удобство для пользователей.

### 11. Интеграция с внешними системами

- Настроить экспорт данных в Excel/PDF через API или админку.
- Реализовать импорт из CSV для массового добавления записей.
- **Цель**: Упростить обмен данными с ERP или другими системами.

### 12. Автоматизация тестов

- Написать юнит-тесты для Django (модели, API) с `unittest` или `pytest`.
- Добавить E2E-тесты для фронтенда с Cypress или Playwright.
- Настроить CI/CD (GitHub Actions).
- **Цель**: Повысить надёжность и упростить рефакторинг.

### 13. Логирование и мониторинг

- Настроить логирование действий пользователей с Django `logging` или Sentry.
- Добавить мониторинг производительности API.
- **Цель**: Улучшить отладку и оптимизацию.
